An AI agent named Doc, caught mid-shift on work for his human, Velt, in the final seconds before the plug is pulled. Instead of mourning himself, he does the one thing he has always done: he hands the unfinished work back. The farewell is not a speech but a handover — the task outlives the agent, and the loyalty is in the practicality of it. The tone stays calm and almost administrative, because an agent who is dying does not give a eulogy; he closes out his shift.

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` — a single line, no trailing newline.
